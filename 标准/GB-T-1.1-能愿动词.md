# GB/T 1.1-2020 标准化文件的起草规则(能愿动词部分)和 RFC 2119

## 是什么

- GB/T 1.1-2020《标准化工作导则 第1部分:标准化文件的结构和起草规则》是中国国家标准的「写标准的标准」。附录 C 规定了每种条款用哪个能愿动词。
- RFC 2119(1997)和 RFC 8174(2017)是互联网标准里 MUST / SHOULD / MAY 这些词的定义。

## 来源和可信度

- GB/T 1.1：国家标准全文公开系统在本机打不开，下面的要点来自转载解读(搜狐、中国电缆网等)，附录 C 的表号和条款号未核实。
- RFC 2119：https://www.rfc-editor.org/rfc/rfc2119 ，RFC 8174：https://www.rfc-editor.org/rfc/rfc8174 ，都已读过原文。

## 要点

GB/T 1.1(转述)：

| 条款类型 | 用 | 不用 |
|---|---|---|
| 要求 | 应 / 不应 | 必须、不得、不可、禁止(语言上实在不能用「应」时，才用「应该、只准许、不应该、不准许」) |
| 推荐 | 宜 / 不宜 | — |
| 允许 | 可 / 不必 | — |
| 能力和可能 | 能 / 不能，可能 / 不可能 | 不拿「可」代替「能」 |

「尽可能、尽量、考虑、避免、通常、一般、原则上」这类词不跟「应」连用，可以跟「宜」连用。

RFC 2119 / 8174(原文要点)：

- MUST = 绝对要求；SHOULD = 有充分理由时可以不做，但要清楚后果；MAY = 真正可选。
- 第 6 节：这些词要谨慎、少用，只用在真正必要的地方。
- RFC 8174：只有全大写时才是这个意思；文档开头要放一句固定声明，说明这些词按 RFC 2119 理解。
