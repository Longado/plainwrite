# ISO 24495-1:2023 简明语言(Plain language)

## 是什么

国际标准化组织 2023 年发布的简明语言标准第一部分。它不限定用词，也不给数字阈值，只规定一份文字要达到的结果：读者能找到、能读懂、能照着做。

## 来源和可信度

ISO 官网打不开，下面的条目名来自二手转述：新西兰标准局的商品页 https://www.standards.govt.nz/shop/iso-24495-12023 和 iplfederation.org 的介绍。转述的不是原文措辞。

## 要点(转述)

四条原则，每条下面有几条指南：

1. **对路(relevant)**：读者得到他需要的内容。先确定读者是谁、他要干什么、在什么场合读、该用哪种文体，再决定写什么。
2. **找得到(findable)**：读者能找到他要的那部分。按读者的需要组织结构，用标题让人预判下文。
3. **看得懂(understandable)**：读者能读懂。用熟悉的词，句子清楚、简洁，段落讲一件事，必要时配图，语气尊重读者，前后连贯。
4. **用得上(usable)**：读者能照着用。写作过程中要评估，和读者一起测试，交付后继续看读者实际怎么用。
