# 参照的标准

plainwrite 的规矩来自下面这些写作标准。每份文件写清四件事：这个标准是什么、来源靠不靠得住、规则要点(用我们自己的话转述，不照抄原文)、plainwrite 用了哪些条目、没用的为什么不用。

| 标准 | 管什么 | 读到的程度 | 文件 |
|---|---|---|---|
| ASD-STE100 Issue 9 | 受控用词、步骤写法 | 二手 | [STE-受控英语.md](STE-受控英语.md) |
| ISO 24495-1:2023 | 简明语言四原则：对路、找得到、看得懂、用得上 | 二手 | [ISO24495-简明语言.md](ISO24495-简明语言.md) |
| 美国联邦简明语言指南、GOV.UK 写作规范 | 主旨先行、主动语态、句段长度 | GOV.UK 原文；美国 2011 版存档 | [美英简明写作指南.md](美英简明写作指南.md) |
| GB/T 1.1-2020、RFC 2119 / 8174 | 应 / 宜 / 可 / 能，规则有多硬 | GB/T 二手；RFC 原文 | [GB-T-1.1-能愿动词.md](GB-T-1.1-能愿动词.md) |
| EARS、INCOSE 需求写作指南 | 触发条件写在前面，一条一件事 | 二手 | [EARS-需求句式.md](EARS-需求句式.md) |
| DITA 1.3 | 按文体分开写：概念、步骤、参考 | 原文 | [DITA-文体分开.md](DITA-文体分开.md) |
| GB/T 15834、GB/T 15835、阮一峰指南、sparanoid 指北 | 标点、数字、句长、中英混排 | 15834 和两份指南是原文；15835 只读到结构 | [中文标点数字与排版.md](中文标点数字与排版.md) |

## 每个标准用到了哪

| 条目 | 来自 | 状态 |
|---|---|---|
| 先想读者 | ISO 24495、美国联邦指南 | 已收：`规范.md` 第一节 |
| 找读者试读 | ISO 24495 | 只在定规矩时用过，日常写作不另起试读回合(作者 10-07 定) |
| 不推荐的词配上替代词 | STE | 已收：`避免词.md` |
| 一个东西一个叫法 | STE | 已收进规范，不做自动检查 |
| 应 / 宜 / 可 / 能，文件开头放图例 | GB/T 1.1、RFC 2119 | 已收：`规范.md` 第四节、`文体/规则.md` |
| 触发条件写在前面，一条一件事 | EARS、INCOSE | 已收：`文体/规则.md` |
| 步骤一句一个动作，警告前置，写清做完的样子 | STE、DITA | 已收：`文体/步骤.md` |
| 主旨先行，一段一个主题 | 美国联邦指南、GOV.UK、阮一峰 | 已收：`规范.md` 第三节、`文体/报告说明.md` |
| 句长、段长的数字 | STE、GOV.UK、阮一峰 | 只作参考：中文实测 Claude 和作者两边一样 |
| 标点、全角半角、中英空格 | GB/T 15834、阮一峰、sparanoid | 只作参考：作者定的 |
| 指代要明确 | 阮一峰 | 已收：`规范.md` 第二节 |
| 全量白名单词典、易读语言、XML 结构 | STE、Inclusion Europe、DITA | 不收 |

易读语言(Inclusion Europe Easy-to-Read，面向阅读困难的读者)也查过，没有对应的读者，没单独写文件。
