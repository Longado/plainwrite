# 美国联邦简明语言指南 和 GOV.UK 写作规范

## 是什么

两国政府给公务写作定的简明写作要求。美国那份配套 2010 年的 Plain Writing Act；GOV.UK 那份是英国政府网站所有内容都要遵守的写作规范。

## 来源和可信度

- 美国：plainlanguage.gov 现在跳转到 https://digital.gov/guides/plain-language。完整目录来自 UNT 网页存档里的 2011 版。
- GOV.UK：https://guidance.publishing.service.gov.uk/writing-to-gov-uk-standards/writing-guidelines/clear-language/ ，下面引号里的话已对过原文。

## 要点

美国联邦指南(转述)：

- 先想读者，再组织内容：多用标题，每节写短。
- 用主动语态，不把动词藏进名词里。表示要求时用 must。
- 句子写短，主旨写在例外和条件前面，不用双重否定。
- 段落有主题句，写短段。
- 要用读者做测试。

GOV.UK(原文)：

- 「Try to split up sentences that are over 25 words long」：超过 25 词的句子试着拆开。
- 「Paragraphs should have no more than 5 sentences each」：一段不超过 5 句。
- 「Use the active voice rather than the passive voice」：用主动语态，不用被动语态。
- 另外几条(转述)：少用 -ion、-ment 结尾的抽象名词；有一张禁用的空话词表，比如 deliver、leverage、facilitate、empower；must 用于法律要求，need 用于行政要求，can 用于可选的事。

## plainwrite 怎么用

| 条目 | 状态 | 在哪 / 为什么 |
|---|---|---|
| 主旨写在例外和条件前面 | 已收 | `文体/报告说明.md`「第一段就是那一句」 |
| 主动语态、不用双重否定 | 只作参考 | `规范.md` 第三节 |
| 25 词句长、5 句段长 | 只作参考 | 英文词数，中文实测两边一样，不定死 |
| 不把动词藏进抽象名词 | 已收(换成中文的说法) | `文体/回复.md`、`避免词.md`「可复核」一类。中文里对应的是「可复核的装置」这种名词化写法，2026-08-13 作者提过意见 |
| 空话禁用词表 | 不照搬 | 英文词表管不到中文。中文的同类词(「赋能」「打造」)作者自己在客户材料里也会用，没过回测门槛 |
| must / need / can 分档 | 已收(换成中文标准) | 用的是 GB/T 1.1 的应 / 宜 / 可，见 `GB-T-1.1-能愿动词.md` |
